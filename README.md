# AimSeg_QuPath_Extension

## GUI Layout Concept

This design outlines a graphical user interface (GUI) for selecting input data, choosing a segmentation model, and performing specific actions.

-------------------------------------
## Input Options
- (o) Brightfield  
- (o) Electron  

## Segmentation Model
- **Dropdown**: Select a pre-trained model  
- **OR**  
- **Path**: Enter a custom model path [Browse]  
- **Toggle**: Use Built-in / Custom  

## Action Buttons
- Inference  
- Update Hierarchy  
- Measure  
-------------------------------------

### Features:
- **Input Options**: Choose between "Brightfield" and "Electron Microscopy."
- **Segmentation Model**: Select a trained model from a dropdown or provide a custom model path.
- **Action Buttons**: Perform tasks such as running the model, updating hierarchy, or measuring results.
